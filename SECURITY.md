# Security

Please report vulnerabilities privately through GitHub: on the repository's **Security** tab,
choose **Report a vulnerability**
([direct link](https://github.com/DeveloperKhan/team-recognizer/security/advisories/new)).
Don't open a public issue for them.

In scope:
- the HTTP API (`server.py`), e.g. ways around `RECOGNIZER_TOKEN` or images that crash or hang it;
- the browser package `@dracoviz/team-recognizer`, e.g. ways for an image or a configured URL to
  run code in the host page;
- the demo page.

Only the latest release is supported.
