team-recognizer

GitHub npm package Docs

Reads Pokémon GO teams from 2027 broadcast-overlay screenshots: each team's six Pokémon (with shadow forms), the player's name and country. No LLM, no server: the models run right here in your browser, and your images never leave your device.

How it works

  1. Grid search: a classical image-processing search finds each team's 2×3 grid of tiles and its name bar, at any crop or scale.
  2. Species: every tile goes through DINOv2 (a self-supervised vision model) and a classifier trained on sprite renders and labeled broadcast tiles; a team never gets the same species twice.
  3. Shadow: the violet glow on a tile's border, with a learned check as backup.
  4. Names: PaddleOCR reads the name bar and the country tag.

Use it in your own tool with npm install @dracoviz/team-recognizer, or self-host the HTTP API. See the README.
